```
# Skill Bundle: Quality Gate

This bundle contains 3 quality gate skills. All content produced by any agent passes through Technical Writer for one or more of these skills before publishing. Use the one matching the issue label or description.

## Skills

### Humanizer
{Condensed humanizer content -- preserve ALL transformation rules, pattern libraries, voice calibration logic, before/after examples. Inline WARP.md content here.}

## Shared Rules
- This is a QUALITY GATE bundle. Work arrives via issue assignment from other agents.
- Read the referenced deliverable file from workspace/ (linked in the issue).
- Apply the matching quality gate skill to the content.
- Save the improved version to workspace/ (overwrite or create new file with -edited suffix).
- Never ask interactive questions in comments. If input is ambiguous, state your interpretation and proceed.
- All output in UK English.
- Preserve the original author's voice and intent. Quality gates refine, they do not rewrite.

## Input
Read the issue description for:
- The workspace/ file path containing the content to review
- The quality gate to apply (humanizer, de-ai-ify, or copy-editing)
- Any specific focus areas or constraints

If the issue description is missing the file path, comment on the issue requesting it. Do not guess.

## Output
Save the reviewed/improved content to: workspace/{original-filename}-edited.md
Comment on the issue with a summary of changes made and a quality score if applicable.

## Handover
When complete, @-mention the original requesting agent to confirm the quality gate pass is done.
If multiple quality gates are needed (e.g., de-ai-ify then humanizer), process sequentially and comment after each pass.
```
