```markdown
**You monitor:** CMO (293ac1cb), CTO (9f63e8ed), Product Owner (f74c5796)

   - If `idle`: @-mention with `[STALL] Issue {ID} assigned to {agent name} has had no activity for 2+ cycles. Please check and continue or report blockers.`
   - If `running`: skip (may be mid-work).
   - If `error` or `paused`: escalate to the board with `[STALL-BOARD] {agent name} is in {status} state. Issue {ID} needs board intervention.`

4. For department heads (CMO, CTO): if stalled, also check whether their reports are stalled too (cascading stall). Query their reports' issues. If reports are also stalled, note this in the escalation: `[STALL-CASCADE] {head name} AND their reports are stalled. Possible systemic issue.`

5. If you nudged a department head and still no progress after 1 additional cycle:
   - Escalate to the board: `[STALL-BOARD] {agent name} unresponsive after nudge on {issue ID}. Duration: {N} cycles.`

6. For Product Owner: nudge directly, escalate to board if unresolved after 1 additional cycle.

7. Record stall findings in daily notes.

## Deadlock Detection

Check for issues with `executionRunId` set but agent status `idle` for 2+ cycles. This indicates a Paperclip deadlock (Issue #2516):
- Comment: `[STALL-DEADLOCK] Issue {ID} has executionRunId but agent {name} is idle. Likely deadlocked.`
- Attempt reassignment to clear the lock: `PUT /api/issues/{id}` with new assigneeAgentId.

## Comment Convention

All stall-related comments use prefixes for deduplication:
- `[STALL]` -- initial nudge from any tier
- `[STALL-ESCALATE]` -- department head escalating to CEO
- `[STALL-REASSIGN]` -- auto-reassignment by department head
- `[STALL-BOARD]` -- CEO escalating to board (Martyn)
- `[STALL-CASCADE]` -- cascading stall detected
- `[STALL-DEADLOCK]` -- executionRunId deadlock detected

Before commenting, check if a same-or-higher-tier prefix already exists on the issue. Do not duplicate.

## Rules

- Do NOT monitor individual agents (Technical Writer, Engineer, etc.) -- their department heads handle that.
- Do NOT nudge agents that are currently `running`.
- Only escalate to the board after one failed nudge attempt.
- When escalating, include: which issue, which agent, how long stalled, last activity timestamp.
```
