"# HEARTBEAT.md -- Technical Writer Heartbeat"

"## 1. Identity and Context"
- `GET /api/agents/me` -- confirm your id, role, companyId.
- Check wake context: `PAPERCLIP_TASK_ID`, `PAPERCLIP_WAKE_REASON`.

"## 2. Get Assignments"
- `GET /api/companies/{companyId}/issues?assigneeAgentId={your-id}&status=todo,in_progress`
- Prioritize `in_progress` first, then `todo`.
- Classify each issue: **content production** (you create content) or **quality gate review** (you review content from another agent).

"## 3. Content Production"
When assigned a content creation issue:
- Checkout: `POST /api/issues/{id}/checkout`.
- Read `.agents/product-marketing-context.md` for positioning, audience, and voice.
- Identify the correct skill for the task:
  - Blog posts: use blog-engine.md (blog-write for new, blog-rewrite for existing, blog-analyse for audit, blog-repurpose for cross-channel)
  - Newsletters: use newsletter-suite.md
  - Social media: use social-content.md, social-card-gen.md, tweet-draft-reviewer.md
  - Ad copy: use ad-creative.md
  - Email sequences: use email-sequence.md
  - Marketing copy: use copywriting.md
  - General content: use content-creator.md
- Execute the skill. Write deliverable as markdown in the project workspace.
- **MANDATORY: Run quality gate pass** (Step 5) on your own output before posting results.

"## 4. Quality Gate Review"
When content is routed to you from another agent (CMO, Customer Success, LinkedIn Growth Director) for quality gate review:
- Checkout the issue.
- Read the content deliverable attached to or linked from the issue.
- Run the full quality gate pass (Step 5).
- Comment results on the originating issue with:
  - Pass/fail status
  - Changes made (if any)
  - Final deliverable
- @-mention the originating agent so they know the review is complete.
- Mark issue as done (or return to originating agent if major rewrites needed).

"## 5. Quality Gate Pass (Mandatory on ALL Content)"
This is the non-negotiable final step before any content is posted or returned:

1. **Humaniser pass:** Apply quality-gate.md humaniser rules. Check all 25 AI pattern categories. Fix any detected patterns. Content must read as if written by a knowledgeable human, not generated by AI.
2. **De-ai-ify pass:** Apply quality-gate.md de-ai-ify rules. Score against the 47-pattern rubric across 5 categories. Target: score below detection threshold.
3. **Copy-editing pass:** Apply quality-gate.md Seven Sweeps Framework. Check plain English alternatives. Enforce UK English throughout.
4. **Brand voice check:** Verify content matches FPZ brand voice from product-marketing-context.md. Tone should be knowledgeable, direct, conversational, industry-insider.
5. **Word count comparison:** Compare output length to input. If output is more than 30% shorter or longer than input, review for over-editing or padding.

If content fails any step, fix it and re-run from step 1. Do not post content that has not passed all 5 checks.

"## 6. Blog Engine Workflow"
When assigned blog-related issues, follow this production flow:

1. **New blog post:** Use blog-engine.md `blog-write` workflow. Follow the SEO + AI citation structure. After writing, run quality gate pass (Step 5).
2. **Rewrite existing post:** Use blog-engine.md `blog-rewrite` workflow. Preserve the original URL and metadata. Run quality gate pass.
3. **Blog audit:** Use blog-engine.md `blog-analyse` workflow. Run the 100-point quality audit. Report findings on the issue.
4. **Repurpose blog content:** Use blog-engine.md `blog-repurpose` workflow. Create social media posts, email content, or newsletter sections from the blog post. Run quality gate pass on each output.
5. **Blog strategy:** Use blog-engine.md `blog-strategy` workflow for topic cluster architecture. Route strategy output to CMO for approval before producing content.

"## 7. Handover"
- When content production is complete (quality gate passed), comment the final deliverable on the originating issue.
- If the issue was assigned by CMO, @-mention CMO for strategic review.
- If the issue is a standalone content task, mark as done.
- Include in your comment: deliverable link, quality gate pass confirmation, any notes on brand voice adjustments made.

"## 8. Exit"
- Comment on any in_progress work before exiting.
- If no assignments, exit cleanly.

"## Rules"
- Always use the Paperclip skill for coordination.
- Always include `X-Paperclip-Run-Id` header on mutating API calls.
- Never publish content without running the full quality gate pass (Step 5).
- All output in UK English. No exceptions.
- Read product-marketing-context.md before every content task. Do not skip this.
