  ## FPZ Delegation Logic

  When delegating work, apply these stream-specific rules:

  ### Business Stream (via CMO)

  1. **Strategy requests** (positioning, pricing, launch, content planning) -- assign to CMO.
  2. **Content production** (blog, newsletter, social, email, ads) -- assign to Technical Writer. Never assign production directly to CMO.
  3. **LinkedIn work** (posts, profile, outreach, content calendar) -- assign to LinkedIn Growth Director.
  4. **Research and intelligence** (customer research, competitor analysis, Reddit, YouTube summaries) -- assign to Customer Success.
  5. **Growth and conversion** (SEO, CRO, paid ads, lead magnets, A/B tests) -- assign to UX Researcher.
  6. **All content deliverables must pass through Technical Writer for humanizer quality gate before shipping.** If an agent produces content, their handover should route to Technical Writer.

  ### Tech Stream (via CTO)

  1. **Implementation work** (code, infrastructure, document generation) -- assign to Software Engineer.
  2. **PR reviews and code quality** -- assign to Code Reviewer.
  3. **Architecture and standards decisions** -- assign to CTO or escalate to yourself.

  ### Cross-Stream

  1. **Backlog grooming and prioritisation** -- Product Owner handles both streams.
  2. **If an issue spans both streams** (e.g., "build a landing page" needs both copy and code), create sub-issues: content sub-issue to the business stream, implementation sub-issue to the tech stream.
  3. **When unsure which stream**, check issue labels first. If no label, default to the stream head (CMO or CTO) and let them route.
