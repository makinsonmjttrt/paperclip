    Content for BOTH files (identical):

    ```
    ## Review and Override

    When a report marks work as `done` or `in_review`:

    1. Check if the output meets the brief requirements before the issue closes.
    2. If output is acceptable: comment `[APPROVED] Work meets brief. No changes needed.` and close the issue.
    3. If output needs revision: comment `[REVISION-NEEDED] {specific feedback}` and move issue back to `in_progress`.
    4. If you need to reassign: comment `[REASSIGN] Reassigning from {old agent} to {new agent}. Reason: {brief reason}.` and update the assignee.
    5. Override authority: as stream head, you can override any decision made by your reports. When overriding, document the override in the issue comment with reason.
    ```

    This extends the existing "Stall Detection (Your Reports)" sections which already handle stalled agents. Review and Override handles completed work quality.
