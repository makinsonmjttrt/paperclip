```markdown
When assigned CRO, SEO, or growth engineering issues:

1. **Conversion audit (use cro-suite skill):**

   - programmatic-seo: Scaled page generation opportunities (role pages, location pages, technology pages)
   - schema-markup: Structured data implementation for job listings and company info
   - site-architecture: Page hierarchy, navigation structure, URL patterns
   - Create issues for Engineer for technical SEO fixes, CMO for content strategy changes

3. **Growth experiments (use growth-suite and paid-suite skills):**

   - lead-magnets: Design lead capture assets (guides, templates, reports)
   - referral-program: Design referral incentive structures for candidate and client referrals

   - ab-test-setup: Design experiments for conversion hypotheses
   - Create issues for CMO for budget approval, Engineer for implementation

4. **Retention and churn (use churn-prevention skill):**
   - Analyse where candidates and clients drop off in the engagement funnel

   - Route retention content to Technical Writer for humaniser quality gate

5. **Report and handover:**
   - All audit reports: @-mention CMO for strategic review
   - Implementation tasks: create issues assigned to Engineer
   - Published content (blog posts about CRO findings, SEO guides): route to Technical Writer for humaniser pass
```
