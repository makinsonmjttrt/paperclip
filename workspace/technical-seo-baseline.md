## 2. Sitemap

**Status: PASS with issues**

- Sitemap index at `fourpointzero.io/sitemap.xml` -- references 10 child sitemaps
- Generated by Yoast SEO
- Page sitemap: **14 URLs**
- Post (blog) sitemap: **63 URLs**
- Additional sitemaps: job listings (Matador), categories, tags, author, locations, types

**Issues:**

The 14-page sitemap includes utility pages that should not be indexed:
- `/maintenance-page/` -- publicly accessible, not noindexed, describes site as "under maintenance"
- `/log-in/` -- user login page, should be excluded from index
- `/sign-up/` -- registration page, should be excluded
- `/my-profile/` -- member area, should be excluded
- `/member-directory/` -- member area, should be excluded

All five pages are in the sitemap AND accessible with no `noindex` meta tag. This wastes crawl budget and risks low-quality pages diluting site authority.

**Fix:** Add `noindex, nofollow` meta robots to these five pages via Yoast SEO (requires WP access). Remove from sitemap once noindexed.

## 4. Schema Markup (from FOU-154)

**Status: PARTIALLY LIVE -- with critical errors**

The JSON-LD implementation is present on all checked pages. The graph includes: WebPage, BreadcrumbList, WebSite, Organization. This confirms the FOU-154 schema work is deployed.

**Critical errors found in Organization schema:**

```json
"name": "FourPointZero Recruitmernt",
"caption": "FourPointZero Recruitmernt"
```

The company name is misspelled as **"Recruitmernt"** (not "Recruitment") in both the `name` field and the logo `caption`. This is what Google indexes as the official company name in structured data. This also mirrors into the logo object.

```json
"logo": {
  "url": "https://fourpointzero.io/wp-content/uploads/2025/01/Twitter-logo.png"
}
```

The organisation logo is set to **Twitter-logo.png** -- a social media icon rather than the company logo. Google uses this image in rich results and Knowledge Panel. This is incorrect.

**Fixes required (via WP / Yoast SEO settings):**
1. Correct organisation name from "FourPointZero Recruitmernt" to "FourPointZero Recruitment"
2. Update organisation logo to the correct company logo asset

**Recommended action:** Create `/creativai/` as a standalone landing page. Even a minimal page captures brand searches and provides a canonical URL to reference in all marketing. Assign to Engineer post CMS-access grant.

## Indexing Status: Blocking Issues?

Based on this audit, **no pages appear to be actively blocked from Google indexing** via robots.txt or noindex directives. The site is crawlable and submittable.

However, there are issues that will suppress ranking performance:
- Schema typos reduce Google's confidence in entity data
- Missing H1 on contact page weakens on-page signals
- Utility pages in sitemap dilute crawl budget quality signals
- PageSpeed unverified -- poor Core Web Vitals can suppress rankings across all pages

**No evidence of a site-wide indexing problem.** The priority is fixing signal quality, not fixing crawlability.
