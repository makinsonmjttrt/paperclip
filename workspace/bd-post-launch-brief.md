## The Situation

CreativAI launches April 17. Every outreach message sent from April 18 has a new asset: a live practice you can name, link to, and let people verify. This changes the opening line, the credibility frame, and the follow-up sequence for every new conversation.

This brief covers four things:

4. What to measure so you know if it is working

## 1. The Hook

**What changed on April 17**

Pre-launch, every message carried an implicit qualifier: "I'm building something." That framing requires the recipient to extend trust on a promise. It works, but it is harder to land with cold contacts who have no prior relationship with FPZ.

Post-launch, you have an asset: CreativAI is live. A prospect can go to the site, read the positioning, and validate the claim independently before replying. That shifts the credibility frame from "trust me, this is coming" to "this exists, here it is."

**How to reference it naturally**

Do not announce the launch in the subject line or as the lead. Use it as a credential anchor midway through the first paragraph.

Before (pre-launch pattern):
> "I run CreativAI at FourPointZero — the AI-focused search practice we've been building over the past year."

After (post-launch pattern):
> "I run CreativAI at FourPointZero — an AI-focused executive search practice we launched last week, built on six years of creative production placement network."

The "launched last week" phrase does two things: it signals active momentum without overstating scale, and it gives the prospect a reason to look. The six-year foundation prevents it from reading as a startup pitch.

**Warm outreach vs cold**

For warm contacts (existing connections, past candidates, prior client relationships):
Lead with the relationship first, then introduce CreativAI as context. Do not treat a warm contact as a product launch announcement opportunity. The message is: "Something shifted in how we operate — and it is relevant to you."

> "Wanted to share something with you — we've just launched CreativAI, the AI-focused arm of FPZ. You've been in this world for a while and I'd value a conversation on what you're seeing. Twenty minutes?"

For cold outreach (batch 4 and 5 contacts):
Use CreativAI as a credibility signal, not a product pitch. The landing page is a background reference, not a link you paste into a message. If asked "what is CreativAI?", you have an answer and a URL. Do not lead with it.

**What to avoid**

Do not say "we just launched" in connection requests — it frames the message as a launch announcement rather than a genuine connection. Do not use the launch as a reason for urgency ("before launch slots fill up", etc.). The launch is a credential, not a campaign.

## 3. Batch 5 Script Update

Batches 1-3 were sent in "building" mode. The connection requests and first messages all carried the framing of a practice in development. Batch 4 (which lands on launch day) has already been updated.

For batch 5 (Wave 2 studios and May targets), the opening line needs to reflect the live practice.

**What to change in the first message**

Old pattern:
> "I run CreativAI at FourPointZero — the AI-focused practice we've been building."

New pattern:
> "I run CreativAI at FourPointZero — the AI executive search practice for creative production, which we launched earlier this month."

That is the only required change. The rest of the message structure (research conversation framing, discovery questions, twenty-minute ask) stays identical.

**What to change in connection requests**

The connection requests in batch 5 are all personalised to the specific studio signal — they should not reference CreativAI by name in the 300-character limit. The practice name is for the follow-up message, not the connection request. Keep existing batch 4 signal hooks as the model.

**What to add if asked "what is CreativAI?"**

> "It's the AI-focused executive search practice within FourPointZero — we launched in April 2026. We're the only specialist search firm I'm aware of operating at the intersection of AI and creative production leadership. You can see the full positioning at fourpointzero.io/creativai."

Keep it one sentence unless they want more.

**Re-engagement of batch 1-3 no-replies**

Any batch 1, 2, or 3 contacts who did not respond can be re-engaged with the launch as a legitimate new hook — provided enough time has passed (minimum 4 weeks from last contact). The message is:

> "Following up from a while back — we've just launched CreativAI, the AI-focused practice at FourPointZero. Given what [COMPANY] is building with [SIGNAL], I'd still value a twenty-minute conversation. Happy to find a time that works."

Do not re-engage batch 1-3 contacts before checking: (a) how many touches they have already received, (b) whether they have been moved to break-up stage, (c) whether there is a more recent signal to reference.

## 4. BD Metrics to Track

Post-launch is the right time to formalise measurement. You now have a defined practice, a live site, and a consistent pitch. Track performance from batch 4 onwards.

**Per batch / per wave**

| Metric | What to count | Target |
|--------|--------------|--------|
| Connection acceptance rate | Accepted / sent | >30% (LinkedIn average is 20-30%; personalised requests with strong signals outperform) |
| First message reply rate | Replies / accepted | >20% |
| Call booking rate | Calls booked / accepted | >10% |
| Call-to-brief conversion | Qualified briefs raised / calls | Track directionally; no target yet |
| Pipeline value | Estimated fee value of qualified conversations | Track by month |

**How to log this**

Update `workspace/bd-pipeline.md` with a response column for each contact as results come in. Status options: Sent / Accepted / Replied / Call Booked / Brief Open / Closed Won / Closed No.

Do not wait until the end of a batch to update. Log each response the day it arrives.

**What to watch for in the first two weeks**

If Wave 1 acceptance rate is below 20% after 7 days: check whether the connection requests are landing correctly (LinkedIn sometimes throttles new send volumes). Do not nudge pending requests. Wait for day 14 before shifting to email.

If first message reply rate is below 10%: review the message against the brief. The most common failure mode is the message reading as a pitch rather than a research conversation. The opening line should be about them, not FPZ.

If no calls booked after Wave 1 completes: check discovery questions for each company. Questions that are too broad do not prompt a "yes, let me think about that" reaction. Tighten to one specific question per first message if needed.
